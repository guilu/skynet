# Entregas de webhooks de GitHub

Cuerpos de entregas de la GitHub App, recortados a lo que usa Skynet, para `GitHubWebhooksIT` y la guía `docs/tests/probar-gh-b.md`. El nombre es `<X-GitHub-Event>-<action>.json`. La firma `X-Hub-Signature-256` no se graba: se calcula al enviarlas, con el secreto de cada prueba.
